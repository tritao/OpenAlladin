# Original Aladdin research inputs

Place authorized local copies of the original materials here when available:

```text
data/original/
├── source/       # M68K assembly archive, including FOLDER.68K
├── rom/          # User-owned or otherwise authorized Genesis image(s)
├── assets/       # Locally extracted Chopper/tUME/ProPack data
└── tools/        # Locally supplied SNASM/Chopper/tUME dependencies
```

These files are ignored by Git unless explicitly authorized. The
publisher-authorized canonical ROM dump is kept at the repository root because
the analysis tools use that path by default.

## Current status

The publicly documented Genesis source archive is held by the Video Game
History Foundation, but the archive’s Aladdin game data is marked restricted.
The VGHF access policy says restricted/raw digital materials are provided only
case-by-case to approved researchers. The original assembly and extracted game
assets remain local research inputs; the authorized ROM dump is present at the
repository root.
